FAQ

Chrome? Same package, Chrome Web Store review pending; load it manually for now.

Does it upload anything? No. The extension asks for one permission, storage, and has no network host permissions.

Encrypted PDFs? Not directly — print to PDF first.

Does compression work on text PDFs? Only the embedded images are re-encoded; text-only files barely shrink.
