DOUDUO PDF Pocket · User guide

Version 1.5.0 ｜ 17 November 2026

Everything is free: merge, compress, split, rotate, watermark, images to PDF.

In one sentence

Merge and compress PDFs in your browser — files are never uploaded; everything is computed on your own machine.

Install (30 seconds)

  1. Store build: search “DOUDUO PDF Pocket” in the Edge Add-ons store and install.
  2. Local build: unzip pdfpocket-1.5.0-local.zip → open edge://extensions (or chrome://extensions) → enable Developer mode → “Load unpacked” → pick the unzipped folder.

You can also skip installing entirely and use the web app.

Merge

Drop two or more PDFs, reorder with ↑↓, click Merge & download. Options:

  • Add watermark — text watermark, defaults to CONFIDENTIAL if left empty.
  • Double-sided — pads odd page counts with a blank page so two-sided printing lines up.
  • Normalise to A4 — every page becomes A4, scaled to fit.
  • Merge a whole folder — picks every PDF in a folder and merges them in name order.

Page sizes, orientation and content are preserved as-is; nothing is rasterised.

Compress

Three levels (light / normal / strong). Compression re-encodes embedded images; scanned pages shrink a lot, text-only PDFs barely change. That is expected — there is nothing heavy to remove.

Split

Split every N pages, or extract specific pages (1-3,5). Batch export downloads every part, numbered in page order.

Rotate

Rotate the whole document or selected pages by 90° / 180° / 270°. Only page orientation changes — selectable text stays selectable.

Watermark

Types text diagonally across every page in a light grey. Leave the field empty to use the default (CONFIDENTIAL). Works with Chinese as well as English.

Images to PDF

JPG or PNG → one A4 page per image, scaled to fit with a 24 pt margin. No OCR: the image stays an image.

Things it cannot do

  • Encrypted PDFs — open it in a viewer, print to PDF, then process the copy.
  • OCR — scanned pages stay images; text is not recognised.
  • Format conversion — no PDF to Word, no Word to PDF.
  • Digital signatures — not supported.

Privacy

The extension has a single permission, storage, and no host permissions. It makes no network requests at all, loads no remote code, and contains no analytics. The web app loads one analytics script (Cloudflare, cookieless) on the marketing pages only — never inside the tool. Files are processed in the tab and never leave the machine.

Get it right every time

  • Output file names follow the source file (contract-merged.pdf, contract+2-merged.pdf); you can edit the name before running.
  • Removing the wrong file is undoable with Ctrl+Z.
  • Ctrl+O opens the file picker; ? shows the keyboard shortcuts.
  • If the interface feels stale after an update, reload the page once — the service worker hands over the new build.
